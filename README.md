# 05 · budget

SQLite personal budget tracker with integer money maths and ASCII charts.

## Run
```bash
python -m budget --help
```

## Test
```bash
pytest projects/05-budget-cli -q
```

See the module docstrings for the design notes; every public function has a test.

## Repository
- GitHub: https://github.com/{owner}/budget-cli
- Python 3.11+ · tests: `pytest` · runtime dependencies: none (standard library only)
